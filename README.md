## 👩‍💻CodSoft_Expense-Tracker
A responsive personal expense tracker to manage income, expenses, and balance using HTML, CSS, and JavaScript.

## ✨ Features
- Add income and expense transactions.
- Display transaction history with dates and categories.
- Automatically calculate total income, total expenses, and current balance.
- Edit and delete transactions.
- Filter transactions by category.
- Save transactions in browser Local Storage.
- Responsive layout for desktop and mobile.
